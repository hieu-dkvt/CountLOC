### [Minor] m1 — `load_identities` chấp nhận `identities:` là `false` / `0` / `''` / `{}` thành danh sách rỗng — `src/loc_counter/identity.py:77,84`
- **Mô tả:** khi sửa N1, code dùng `isinstance(data.get("identities") or [], list)`, nên mọi giá trị "falsy" đều thành `[]`. Spec 5.1.3 chỉ miễn cho trường hợp giá trị rỗng (`identities:` → `None`); giá trị không phải list thì phải ném IdentityError.
- **Kịch bản (đã chạy):** file `identities: false`, `identities: 0`, `identities: ''`, `identities: {}` đều được đọc thành `rules == ()`, không báo lỗi. Người dùng viết nhầm (vd. `identities: {}` thay vì `[]`) sẽ không biết file của mình bị bỏ qua hoàn toàn. Hệ quả chỉ là không gộp account; không sai số liệu so với "không có quy tắc".
- **Đề xuất sửa:** `items = data.get("identities"); if items is None: items = []; elif not isinstance(items, list): raise …`. Thêm ca `identities: {}` / `identities: false` vào TC-04.
- **Tham chiếu:** identity spec 5.1.3, mục 7 "Cấu trúc sai".
